# Integración de JavaScript, Tailwind CSS y Flask

Aplicación web de cotización de productos desarrollada para demostrar la integración entre JavaScript, Tailwind CSS y Flask.

El usuario puede seleccionar un producto, ingresar una cantidad y obtener automáticamente el precio unitario, el total y la disponibilidad. JavaScript envía los datos mediante `fetch()`, Flask realiza las validaciones y cálculos, y Tailwind CSS junto con CSS personalizado presenta una interfaz clara y adaptable.

## Tecnologías utilizadas

- Flask
- JavaScript
- Tailwind CSS
- HTML
- CSS
